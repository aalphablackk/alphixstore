
# 🛍️ Alphix Store — E-Commerce & Store Management Platform

Alphix Store is a full-stack e-commerce and store management platform built with **Python and Django**.

It manages the complete shopping lifecycle from product discovery and cart operations to inventory, orders, Paystack payments, email notifications, and staff management.

The project demonstrates how **business logic, databases, authentication, payments, APIs, cloud storage, and deployment** work together as one complete product.

---

## 🚀 Core Features

- 🛍️ Product Catalog, Categories & Brands
- 🔎 Search, Filtering & Sorting
- 🖼️ Product Images & Specifications
- 📦 Inventory & Stock Management
- 🛒 Shopping Cart & Stock Validation
- 👤 Customer Registration & Authentication
- 🔐 Role-Based Staff Access
- 📋 Order Management & Tracking
- 💳 Paystack Payment Integration
- 📧 Automated Email Notifications
- 🖼️ Cloudinary Media Storage
- 🔌 Product REST API
- 👨‍💼 Store Management Dashboard
- ☁️ Cloud Deployment

## 🧠 Engineering Focus

Alphix Store focuses on real-world e-commerce business logic rather than basic CRUD.

The system handles:

- Inventory validation & stock reservation
- Cart and order processing
- Payment verification & failure handling
- Payment expiration & stock release
- Authentication & authorization
- Product and inventory management
- Email notifications
- REST API integration
- Cloud media storage
- PostgreSQL data management
